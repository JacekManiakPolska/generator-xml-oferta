Podstawy

Czym jest plik XML?

XML to uporządkowany plik tekstowy służący do przechowywania i wymiany danych między systemami. Może zawierać różne informacje, np. produkty, ceny, zamówienia, dokumenty lub ustawienia. Ten generator pracuje z plikami XML zawierającymi oferty produktowe.

<name>Adapter USB</name>
<price>29.90</price>
Warto wiedziećPorada 1/3

Użyj bezpośredniego adresu do pliku .xml. Link powinien zaczynać się od http:// lub https://.

Bezpieczne przetwarzanie

  • Obsługa źródeł HTTP i HTTPS
  • Blokada localhost i jawnych prywatnych adresów IP
  • Maksymalnie 3 kontrolowane przekierowania adresu pliku XML
  • Weryfikacja celu każdego przekierowania adresu pliku XML
  • Kontrola deklarowanego rozmiaru pliku do 50 MB
  • Bez trwałego zapisywania oferty
